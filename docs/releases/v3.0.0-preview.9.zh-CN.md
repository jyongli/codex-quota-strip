## 本机 Token 数直接显示

- API Key／第三方 Token 模式在托盘显示 `Tok` 和简写数量；顶部／左侧条及设置显示 `本次已用 1.3K Token | 剩余 —`，悬停和设置说明提供完整整数。
- 只统计本次程序运行期间成功记录的完成／中断请求，不是账户总用量或账单。重启、认证变化、记录开关或日志目录变更后重计；修改语言／刷新间隔不清零，原历史 CSV 保留。
- 沿用现有监听和持久去重，只加真实总 Token，缓存和推理子项不重复叠加；重复来源和手动刷新不增加计数。关闭／失效时显示 `—`；部分／缺失或超过 4096 条显示统计下限 `+`，历史日志仍继续记录。
- 普通官方 API Key 无法通过本程序直接读取账户余额，剩余保持 `—`。本功能不需要 Admin Key，不增加网络查询、轮询或常驻服务。
- ChatGPT 订阅模式继续显示实际剩余百分比，工作请求列表／图表保留。

## 选择下载包

| 系统／用途 | 文件 |
| --- | --- |
| Windows 10 1809+／11，Intel 或 AMD x64 | `CodexQuotaStrip-windows-x64-setup.exe`，当前用户安装向导。 |
| Windows x64 免安装 | `CodexQuotaStrip-windows-x64.zip`，解压运行；Windows 11 ARM64 模拟未实机验证。 |
| Ubuntu 22.04／24.04、Debian 12，amd64 | `CodexQuotaStrip-linux-x86_64.deb`，用 apt 安装。 |
| Fedora 43，x86_64 | `CodexQuotaStrip-linux-x86_64.rpm`，用 dnf 安装。 |
| 其他 glibc Linux x86_64／无 sudo | `CodexQuotaStrip-linux-x86_64.tar.gz`，解压后 `bash install.sh`；需系统运行库。 |
| macOS 14+，Apple Silicon 或 Intel | 推荐通用 `.dmg` 拖放安装，也可选 `.pkg` 或 `.zip`。 |

升级前从托盘／菜单栏退出旧版，再安装新版或替换便携文件；沿用原目录可保留设置和日志。Linux 窗口跟随限 X11，Wayland 使用托盘模式。macOS 仍为 ad-hoc 签名，尚未 Developer ID 签名／公证；窗口跟随需辅助功能权限。

`SHA256SUMS.txt` 校验发布附件，`BUILD-INFO.txt` 标识源码和构建；`Source code` 两项为源码。
