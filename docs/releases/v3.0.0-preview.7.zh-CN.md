# v3.0.0-preview.7 更新说明

**中文** | [English](v3.0.0-preview.7.en.md) · [下载本版](https://github.com/jyongli/codex-quota-strip/releases/tag/v3.0.0-preview.7)

![应用图标](../../assets/icons/app-128.png)

本版为程序补上统一的应用图标：深色圆角底配薄荷绿配额环和两根刻度条。保留 preview.6 的额度历史、每请求 Token、所属对话及其他功能。

## 图标显示位置

- Windows：EXE、桌面／开始菜单快捷方式、配置／历史窗口以及安装器。嵌入 16–256 像素的七档图标，无需另外携带 ICO 文件运行。
- Linux：应用菜单与原生窗口；DEB／RPM 安装主题图标，TGZ 用户安装保留私有图标，自定义安装目录也可使用。
- macOS：应用包、Finder 和原生应用界面，ICNS 包含普通与 Retina 表示，最大 1024 像素。
- 托盘／菜单栏继续使用实时额度数字。图标加载不增加后台服务、轮询或网络请求。

图标为本项目原创矢量图，沿用 MIT 许可。源 SVG 与生成文件均包含在源码中；正常构建／运行无需 Python 或 ImageMagick。

## 选择下载包

| 系统／用途 | 文件 |
| --- | --- |
| Windows 10 1809+／11，Intel 或 AMD x64 | `CodexQuotaStrip-windows-x64-setup.exe`，当前用户安装向导。 |
| Windows x64 免安装 | `CodexQuotaStrip-windows-x64.zip`，解压运行；Windows 11 ARM64 模拟尚未实机验证。 |
| Ubuntu 22.04／24.04、Debian 12，amd64 | `CodexQuotaStrip-linux-x86_64.deb`，用 apt 安装。 |
| Fedora 43，x86_64 | `CodexQuotaStrip-linux-x86_64.rpm`，用 dnf 安装。 |
| 其他 glibc Linux x86_64／无 sudo | `CodexQuotaStrip-linux-x86_64.tar.gz`，解压后 `bash install.sh`；需系统运行库。 |
| macOS 14+，Apple Silicon 或 Intel | 推荐 `CodexQuotaStrip-macos-universal.dmg` 拖放安装；也可选 `.pkg` 安装向导或 `.zip`。 |

升级前从托盘／菜单栏退出旧版，再安装新版或替换便携文件；沿用原目录可保留设置和日志。Linux 需 GTK3／Ayatana／X11 等运行库，窗口跟随限 X11；Wayland 使用托盘模式。macOS 仍是 ad-hoc 签名，尚未 Developer ID 签名／公证，窗口跟随需用户授予辅助功能权限。

`SHA256SUMS.txt` 校验发布附件，`BUILD-INFO.txt` 标识源码和构建；`Source code` 两项为源码。安装／卸载检查覆盖自有图标移除及其他用户文件保留。
