# v3.0.0-preview.6 Release Notes

[中文](v3.0.0-preview.6.zh-CN.md) | **English** · [Download this release](https://github.com/jyongli/codex-quota-strip/releases/tag/v3.0.0-preview.6)

This release adds quota history, per-request token details and source conversations, and fixes the strip covering companion settings/history windows. Windows, Linux and macOS provide native list/chart viewers and Chinese/English interfaces.

## Changes

- **Quota history**: daily CSV files in a selected directory record remaining quota, changes in percentage points, source and time. Switch between List and Chart; valid points connect, boundary references are dashed and missing values remain disconnected.
- **Per-request usage**: inspect input, cached input, cache-write, output, reasoning and total tokens, completion/interruption status and reference account snapshots. Incomplete observations are marked Partial.
- **Source conversations**: the Conversation column follows Time. It shows current titles, or parent titles and agent names for identifiable subagent requests. Missing titles fall back to IDs; unidentifiable sources stay Unknown. Refresh picks up renamed titles; raw IDs remain in the last column.
- **Legacy attribution**: a read-only local history ID index can resolve up to the newest 128 requests missing sources. Conflicts, timeouts or missing indexes stay unknown. Titles are display-only and are not appended to CSV files.
- **Overlay fix**: Windows Store cache paths no longer cause companion windows to be mistaken for Codex. Foreground settings/history/request windows hide the strip; returning to Codex restores it.
- **Low-resource operation**: filesystem/window events remain in use. Viewing history or titles adds no model calls, resident query service or polling. Proxy reuse, configurable refresh, weekly-only display and language switching remain available.

Account quota changes may include concurrent work and are not an independently attributable per-request charge. Actual amounts show “—” when unavailable; subscription percentages are not converted into money. Cached input is part of input and reasoning is part of output, so they are not added again to the total.

## Update and start

1. Quit the previous app from its tray/menu bar, then install the new package or replace portable files. Reusing the path preserves settings/logs; installers do not change existing Codex launchers or login startup.
2. Open Settings, confirm the quota/request history switch and directory, then save. Subsequent observed completions begin recording.
3. Open Quota history or Work requests and choose List/Chart. Refresh only rereads local data. On Windows, `CodexQuotaStrip.exe --requests` opens the request page directly.

Recording covers observed events. Reads are bounded, so incomplete records or earlier usage cannot always be recovered in full.

## Compatibility and verification limits

- Linux uses an Ubuntu 22.04 build baseline. Installation checks cover Ubuntu 22.04/24.04, Debian 12 and Fedora 43. Window following requires X11; Wayland uses tray mode.
- Hosted Windows checks cover native interactions and installation/upgrade/removal, without implying device validation of every Windows version or ARM64 system.
- macOS packages contain both architectures and undergo package/UI checks. Apps have ad-hoc integrity signing only, without Developer ID/notarization, so first launch may be blocked. Window following requires user-granted Accessibility, without Screen Recording permission.
- Legacy attribution reuses system SQLite. Unavailable libraries/indexes leave sources unknown while other quota/token features remain usable. Titles and logs are not automatically uploaded.
