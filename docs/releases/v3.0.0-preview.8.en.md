# v3.0.0-preview.8 release notes

[中文](v3.0.0-preview.8.zh-CN.md) | **English** · [Download this release](https://github.com/jyongli/codex-quota-strip/releases/tag/v3.0.0-preview.8)

## Clear API-key and Token login states

- API keys and external providers now use one clear `API` tray indicator and a bilingual mode message in the strip and Settings.
- Empty subscription metrics are replaced with an explanation. Open Work requests for confirmed local token counts in a list or chart; unknown charges and missing data stay `—`. Provider balances/bills remain in the provider dashboard.
- Only rejected quota or missing supported windows trigger a safe account-summary read in the same short-lived app-server. No keys are read, no models are invoked and no polling is added.
- ChatGPT access tokens keep actual subscription quotas. Mode changes restore the appropriate indicators, signed-out/network failures remain distinct, and unavailable quotas create no fabricated history.
- Existing application icons, proxy reuse, Chinese/English UI, quota history and conversation labels remain available.

## Choose a download

| System / usage | File |
| --- | --- |
| Windows 10 1809+ / 11, Intel or AMD x64 | `CodexQuotaStrip-windows-x64-setup.exe`, a per-user installation wizard. |
| Portable Windows x64 | `CodexQuotaStrip-windows-x64.zip`, extract and run; Windows 11 ARM64 emulation has not been device-tested. |
| Ubuntu 22.04/24.04 or Debian 12, amd64 | `CodexQuotaStrip-linux-x86_64.deb`, install with apt. |
| Fedora 43, x86_64 | `CodexQuotaStrip-linux-x86_64.rpm`, install with dnf. |
| Other glibc Linux x86_64 / no sudo | `CodexQuotaStrip-linux-x86_64.tar.gz`, extract and run `bash install.sh`; system runtime libraries are required. |
| macOS 14+, Apple Silicon or Intel | Recommended: `CodexQuotaStrip-macos-universal.dmg` for drag-and-drop installation; `.pkg` and `.zip` are also available. |

Quit the previous app before installing or replacing portable files. Reusing the directory preserves settings/logs. Linux requires GTK3/Ayatana/X11 runtimes; window following requires X11 and Wayland uses tray mode. macOS retains ad-hoc signing without Developer ID/notarization; window following requires user-granted Accessibility.

Use `SHA256SUMS.txt` to check assets and `BUILD-INFO.txt` for source/build provenance. The two Source code downloads are for developers. Installer/removal checks cover removal of owned icons and preservation of unrelated user files.
