# v3.0.0-preview.11 更新说明

**中文** | [English](v3.0.0-preview.11.en.md) · [下载与发布包体积对比](https://github.com/jyongli/codex-quota-strip/releases/tag/v3.0.0-preview.11)

## 这版做了什么

- Windows 托盘模式不再创建隐藏的悬浮窗；切回托盘模式会释放窗口和字体。首次启用在线查询时才创建查询线程，健康空闲时不做周期恢复检查。
- Windows 对同一条会话事件只解析一次，供额度与 Token 统计共用。三平台读完大日志后释放空闲缓冲，保留尚未写完的行。
- 三平台优化编译和打包。移除图标中间文件，保留现有透明度与分辨率。Windows 便携版仍无需安装 Visual C++ 运行库。

实时刷新、窗口跟随、历史与 Token 统计保留。Windows 登录自启与可选守护服务继续独立设置。

## Windows 本机资源实测

对照 preview.10；同一台 Windows x64 机器、托盘模式、关闭在线查询、使用合成日志。以下是配额主进程的观测值，不含 Codex、短时查询进程或可选守护服务。

| 指标 | preview.10 | preview.11 |
| --- | ---: | ---: |
| 空闲线程数 | 4 | 3 |
| 空闲私有内存 | 2,064 KiB | 2,000 KiB |
| 空闲工作集 | 12,780 KiB | 12,012 KiB |
| 32 秒内累计 CPU 时间增量 | 15.625 ms | 0 ms（测量精度内） |
| 读完 24 个约 30 KB 日志后的私有内存 | 2,864 KiB | 2,060 KiB（−28.1%） |
| 上述日志场景中，9 次追加到状态更新的中位延迟 | 78.2 ms | 79.0 ms |

这是本机构建的受控样本，不能代表所有电脑、账号和会话负载，也不用于推算 Linux 或 macOS 的资源占用。实际发布附件的体积对比见上方发布页。

## 选择安装包

| 环境 | 选用 |
| --- | --- |
| Windows 10 1809+／11，Intel 或 AMD x64 | `CodexQuotaStrip-windows-x64-setup.exe` 当前用户安装，或 `CodexQuotaStrip-windows-x64.zip` 便携版。完整解压并保留相邻的守护组件。 |
| Ubuntu 22.04／24.04、Debian 12，amd64 | `CodexQuotaStrip-linux-x86_64.deb`，用 `sudo apt install ./CodexQuotaStrip-linux-x86_64.deb` 安装。 |
| Fedora 43，x86_64 | `CodexQuotaStrip-linux-x86_64.rpm`，用 `sudo dnf install ./CodexQuotaStrip-linux-x86_64.rpm` 安装。 |
| 其他 glibc Linux x86_64／无 sudo | `CodexQuotaStrip-linux-x86_64.tar.gz`，解压后执行 `bash install.sh`；需要系统运行库。 |
| macOS 14+，Apple Silicon 或 Intel | `CodexQuotaStrip-macos-universal.dmg` 拖入 Applications，或选用同名 `.pkg` 安装包／`.zip` 应用包。 |

升级前先退出旧程序，沿用原安装位置以保留配置与 CSV。已注册 Windows 守护服务时，更新守护组件前请先移除旧服务，更新后重新注册。Linux 悬浮条需要 X11；Wayland 可使用托盘。macOS 预览包为 ad-hoc 签名，未公证；窗口跟随需要辅助功能权限。Windows ARM64 模拟和 macOS 14 实机未单独验证。
