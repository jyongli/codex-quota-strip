# v3.0.0-preview.10 release notes

[中文](v3.0.0-preview.10.zh-CN.md) | **English** · [Download this release](https://github.com/jyongli/codex-quota-strip/releases/tag/v3.0.0-preview.10)

## Windows changes

- **Login startup:** enable “Start at Windows login (applies immediately)” in Settings. It manages the current user's startup entry without administrator rights. Switching it off removes this installation's entry.
- **Optional watchdog service:** select “Register watchdog service…” and approve administrator elevation with the same Windows account. The service watches an already-started companion, recovers abnormal exits under the same user and login session, and allows at most three recovery attempts. A normal tray exit stays closed. It does not open a desktop UI before login. Also enable login startup to launch automatically after sign-in. Both features are off by default.
- **Compact Settings:** reduce content height from 994 to 734 logical pixels, put display/language selectors side by side, and align directory and service controls on shared rows. Keep 14-pixel body text and scrolling on smaller screens.
- **Prevent accidental changes:** only the right-hand slider responds to mouse activation; labels and blank space do not toggle it, and releasing outside the slider cancels. Wheel input over a closed selector scrolls the page without changing the selection. Keyboard and open-list interaction remain available.
- **Painting fixes:** repaint the whole switch after state changes to remove native checkbox remnants. Batch child-window movement and double-buffer Settings to reduce scroll flicker.

The watchdog waits for process-exit events without periodic process scans, screen capture or extra quota network queries. Registration requires elevation by the same account; a different administrator's credentials are rejected. The desktop companion runs with the signed-in user's permissions. Local verification covered normal-exit suppression and actual crash recovery under the original user/session, plus isolated startup registry, pipe permissions and source-image checks.

Linux/macOS packages are rebuilt from the same source commit and retain their existing features. This release's startup, watchdog and compact-layout changes apply only to Windows.

macOS builds move to the supported macOS 15 hosted environment while retaining the 14.0 deployment target; macOS 14 has not been tested separately on a physical device.

## Choose a download

| Environment | File and installation |
| --- | --- |
| Windows 10 1809+ / 11, Intel or AMD x64 | `CodexQuotaStrip-windows-x64-setup.exe`: per-user installation wizard. |
| Portable Windows x64 | `CodexQuotaStrip-windows-x64.zip`: extract everything and run `CodexQuotaStrip.exe`; keep `CodexQuotaGuard.exe` beside it. Physical Windows 11 ARM64 emulation remains untested. |
| Ubuntu 22.04/24.04 or Debian 12, amd64 | `CodexQuotaStrip-linux-x86_64.deb`: `sudo apt install ./CodexQuotaStrip-linux-x86_64.deb`. |
| Fedora 43, x86_64 | `CodexQuotaStrip-linux-x86_64.rpm`: `sudo dnf install ./CodexQuotaStrip-linux-x86_64.rpm`. |
| Other glibc Linux x86_64 / no sudo | `CodexQuotaStrip-linux-x86_64.tar.gz`: extract and run its `bash install.sh`; system runtime libraries are required. |
| macOS 14+, Apple Silicon or Intel | Recommended: `CodexQuotaStrip-macos-universal.dmg` drag-and-drop install. Alternatively use the `.pkg` wizard or `.zip` app archive. |

Quit the old companion before updating; install into the same directory or replace the portable files to preserve settings and CSV logs. Remove the service and disable the old startup entry before moving/deleting a portable directory. Remove and re-register the service when updating its component. The new Windows uninstaller removes this installation's startup entry/service; cancelling service-removal authorization aborts uninstall and preserves the files.

Linux overlay following requires X11; use the tray on Wayland. macOS packages remain ad-hoc signed without Developer ID signing/notarization; following requires Accessibility permission. `SHA256SUMS.txt` verifies attachments, `BUILD-INFO.txt` identifies the source/build, and the two `Source code` downloads are source archives.
