# v3.0.0-preview.10 更新说明

**中文** | [English](v3.0.0-preview.10.en.md) · [下载本版](https://github.com/jyongli/codex-quota-strip/releases/tag/v3.0.0-preview.10)

## Windows 新增与修复

- **登录自启**：配置中打开“开机启动（登录后，立即生效）”，管理当前用户的启动项，无需管理员。取消开关会移除本安装的登记。
- **可选守护服务**：单独点击“注册守护服务…”，以当前 Windows 账号批准管理员提示。服务监护已启动的配额程序，异常退出后在同一用户、同一登录会话恢复，最多尝试三次；从托盘主动退出不会重启。服务本身不在登录前打开界面。需要登录后自动运行时，同时启用登录自启。两项默认均关闭。
- **紧凑配置页**：内容高度由 994 缩至 734 个逻辑像素，显示与语言并排，目录、服务状态采用同排布局；保留 14 像素正文和小屏滚动。
- **避免误操作**：只有右侧滑块响应鼠标点击，点击文字／空白不切换，移出滑块后松开会取消。收起的下拉框不再随滚轮改选项，而是滚动页面；键盘和展开列表继续正常使用。
- **重绘修复**：开关状态同步完整重绘，不再残留左侧原生复选框；滚动采用批量控件移动和双缓冲，减少闪烁。

守护服务等待进程退出事件，平时不定时扫描进程、不抓屏，也不增加额度网络查询。注册只允许当前账号提权，不接受其他管理员账号代为注册；配额程序以登录用户权限运行。已验证本机正常退出保持关闭、异常退出在原用户和会话恢复，以及隔离注册表、管道权限和源映像校验。

Linux／macOS 本轮提供同一源码提交的重新构建包，继续保留原有功能；本轮自启、守护和紧凑布局改动仅适用于 Windows。

## 选择下载包

| 系统／用途 | 文件与安装方式 |
| --- | --- |
| Windows 10 1809+／11，Intel 或 AMD x64 | `CodexQuotaStrip-windows-x64-setup.exe`，当前用户安装向导。 |
| Windows x64，免安装 | `CodexQuotaStrip-windows-x64.zip`，完整解压并运行 `CodexQuotaStrip.exe`；保留旁边的 `CodexQuotaGuard.exe`。Windows 11 ARM64 模拟尚未实机验证。 |
| Ubuntu 22.04／24.04、Debian 12，amd64 | `CodexQuotaStrip-linux-x86_64.deb`，执行 `sudo apt install ./CodexQuotaStrip-linux-x86_64.deb`。 |
| Fedora 43，x86_64 | `CodexQuotaStrip-linux-x86_64.rpm`，执行 `sudo dnf install ./CodexQuotaStrip-linux-x86_64.rpm`。 |
| 其他 glibc Linux x86_64／无 sudo 权限 | `CodexQuotaStrip-linux-x86_64.tar.gz`，解压后执行包内 `bash install.sh`；需系统运行库。 |
| macOS 14+，Apple Silicon 或 Intel | 推荐 `CodexQuotaStrip-macos-universal.dmg` 拖放安装；也可选 `.pkg` 安装向导或 `.zip` 应用包。 |

升级前从托盘／菜单栏退出旧程序，沿用原目录安装或替换文件，保留用户配置和 CSV。便携版移动／删除旧目录前，先在旧配置中移除守护服务、关闭自启；服务组件更新时也应先移除旧服务再重新注册。Windows 新安装器卸载时会清理本安装登记的自启及服务；取消服务移除授权会中止卸载并保留文件。

Linux 配额条跟随需要 X11；Wayland 使用托盘。macOS 仍为 ad-hoc 签名，未 Developer ID 签名／公证；窗口跟随需要辅助功能权限。`SHA256SUMS.txt` 校验附件，`BUILD-INFO.txt` 标识源码及构建，`Source code` 两项为源码。
