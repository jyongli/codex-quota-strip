# v3.0.0-preview.6 更新说明

**中文** | [English](v3.0.0-preview.6.en.md) · [下载本版](https://github.com/jyongli/codex-quota-strip/releases/tag/v3.0.0-preview.6)

本版新增额度变化日志、每次工作请求的 Token 明细与所属对话，并修复配额条遮挡配置／历史窗口的问题。Windows、Linux 和 macOS 均提供原生列表、图表及中英文界面。

## 新增与修复

- **额度变化日志**：选择日志目录后按日保存 CSV，查看剩余额度、变化百分点、来源和时间。列表与图表可切换；有效点相连，重置／来源边界用虚线参考连接，缺失值不连线。
- **每次工作请求用量**：查看输入、缓存命中、缓存写入、输出、推理输出及总 Token，保留完成／中断状态与参考账户快照。不完整数据标记“部分记录”。
- **所属对话**：时间后直接显示对话标题；能确认的子代理请求显示父对话及代理名。标题缺失时回退到 ID，不能确认来源时显示“未识别对话”。刷新后可读取重命名后的标题，末列保留原始 ID。
- **旧记录补认**：通过只读的本地历史 ID 索引尝试补认最近 128 条缺失来源；重复、超时、索引缺失时保持未知。标题只在内存显示，不追加到 CSV。
- **遮挡修复**：Windows 商店版 Codex 的缓存路径不再使插件误识别自己的窗口。配置、额度历史或工作请求窗口在前台时隐藏配额条，切回 Codex 后恢复。
- **低资源运行**：沿用文件／窗口事件；查看历史与标题不会新增模型请求、常驻查询服务或后台轮询。保留代理复用、可调刷新、周额度单独显示和中英文切换。

账户额度变化可能包含并发工作，不能当作单次请求的独立扣费。上游未提供实际金额时显示“—”；不按订阅百分比换算金额。缓存输入已包含在输入中，推理输出已包含在输出中，不能重复加进总 Token。

## 升级与开始使用

1. 从托盘／菜单栏退出旧版，再安装新版或替换便携文件。沿用原路径可保留设置和日志；安装器不修改已有 Codex 启动器或登录自启。
2. 打开配置，确认“记录额度与工作请求”或对应的历史开关，以及所需日志目录；保存后开始记录后续完成的请求。
3. 打开“额度变化”或“工作请求”，选择列表／图表。历史窗口的“刷新”仅重读本地数据。Windows 可运行 `CodexQuotaStrip.exe --requests` 直接打开请求页。

新记录只覆盖程序监听到的事件；超过有界读取范围的数据可能不完整，不能保证全量恢复此前的用量。

## 兼容与验证边界

- Linux 以 Ubuntu 22.04 为构建基线；安装验证覆盖 Ubuntu 22.04／24.04、Debian 12、Fedora 43。X11 支持窗口跟随；Wayland 使用托盘模式。
- Windows 的托管环境验证原生交互与安装／升级／卸载；不代表所有 Windows 版本及 ARM64 设备均已实机验证。
- macOS 包含两种架构并验证安装包与界面。应用只有 ad-hoc 完整性签名，无 Developer ID／公证；首次打开可能被系统阻止。窗口跟随需自行授予辅助功能权限，不请求录屏权限。
- 历史来源补认复用系统 SQLite；系统库或本地索引不可用时保留未知来源，其他额度／Token 功能继续运行。日志与标题不自动上传。
