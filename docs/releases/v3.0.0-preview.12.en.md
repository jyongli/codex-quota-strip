# v3.0.0-preview.12 release notes

[中文](v3.0.0-preview.12.zh-CN.md) | **English** · [Downloads and full measurements](https://github.com/jyongli/codex-quota-strip/releases/tag/v3.0.0-preview.12)

This release reduces memory use during log processing. Common UUIDs are packed losslessly, preserving case and thread/turn identity; eviction queues no longer duplicate IDs. Request CSV files are read in chunks, and restart deduplication retains only the fields it needs. Windows releases the previous history snapshot when switching pages. Existing CSV formats, record limits, and settings remain compatible.

The release page compares preview.11 and preview.12 on the same Windows machine: idle private memory and working set, memory after 4,096 synthetic requests, and peak private commit for the first write with 2,000 existing history rows. Binary and installer sizes come from the actual release assets.
