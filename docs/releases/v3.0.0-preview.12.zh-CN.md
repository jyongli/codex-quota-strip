# v3.0.0-preview.12 更新说明

**中文** | [English](v3.0.0-preview.12.en.md) · [下载与完整实测对比](https://github.com/jyongli/codex-quota-strip/releases/tag/v3.0.0-preview.12)

这版减少了日志处理时的内存占用。常见 UUID 使用无损紧凑格式，保留大小写和会话／请求身份；淘汰队列不再复制 ID。工作请求 CSV 分块读取，重启时只保留去重所需的数据。Windows 切换历史页面时释放上一页快照。既有 CSV 格式、记录上限和配置保持兼容。

发布页列出了与 preview.11 的 Windows 同机测试：空闲私有内存和工作集、处理 4,096 条合成请求后的内存、以及已有 2,000 条历史时首次写入的私有提交峰值。三平台程序和安装包体积取自实际发布附件。

| 环境 | 选包 |
| --- | --- |
| Windows x64，Windows 10 1809+／11 | `CodexQuotaStrip-windows-x64-setup.exe` 当前用户安装，或 `CodexQuotaStrip-windows-x64.zip` 便携版。 |
| Ubuntu 22.04／24.04、Debian 12，amd64 | `CodexQuotaStrip-linux-x86_64.deb`，用 `sudo apt install ./CodexQuotaStrip-linux-x86_64.deb` 安装。 |
| Fedora 43，x86_64 | `CodexQuotaStrip-linux-x86_64.rpm`，用 `sudo dnf install ./CodexQuotaStrip-linux-x86_64.rpm` 安装。 |
| 其他 glibc Linux x86_64／无 sudo | `CodexQuotaStrip-linux-x86_64.tar.gz`，解压后执行 `bash install.sh`；需要系统运行库。 |
| macOS 14+，Apple Silicon 或 Intel | 选通用 `.dmg`、`.pkg` 或 `.zip`。预览包为 ad-hoc 签名，未公证。 |

升级前先退出旧程序，沿用原目录以保留配置和日志。更新 Windows 守护组件时，先移除旧服务，更新后重新注册。详见[安装与兼容说明](../installers.zh-CN.md)。
