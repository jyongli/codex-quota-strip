# v3.0.0-preview.11 release notes

[中文](v3.0.0-preview.11.zh-CN.md) | **English** · [Downloads and release size comparison](https://github.com/jyongli/codex-quota-strip/releases/tag/v3.0.0-preview.11)

## Changes

- Windows creates the overlay only when enabled and releases the window and fonts when returning to tray-only mode. The online query thread starts when first needed. Recovery checks stop while the app is healthy and idle.
- Windows shares one session-event parse between quota and token accounting. All platforms release idle buffers after reading large logs and retain unfinished lines for the next write.
- Smaller release builds and packages across all platforms. Intermediate icon images were removed while retaining the existing alpha and resolutions. The portable Windows build still needs no separate Visual C++ runtime.

Live refresh, window following, history and token accounting remain available. Windows login startup and the optional watchdog remain separate settings.

## Windows resource measurements

Compared with preview.10 on the same Windows x64 machine, in tray-only mode with online queries disabled and synthetic logs. These are observations of the companion process, excluding Codex, temporary account queries and the optional watchdog.

| Metric | preview.10 | preview.11 |
| --- | ---: | ---: |
| Idle threads | 4 | 3 |
| Idle private memory | 2,064 KiB | 2,000 KiB |
| Idle working set | 12,780 KiB | 12,012 KiB |
| CPU time added over 32 idle seconds | 15.625 ms | 0 ms (measurement resolution) |
| Private memory after 24 logs of about 30 KB each | 2,864 KiB | 2,060 KiB (−28.1%) |
| Median append-to-status latency, 9 samples in the log scenario | 78.2 ms | 79.0 ms |

This controlled sample uses local builds; other computers, accounts and workloads will vary. It does not estimate Linux or macOS resource use. See the release page for measured download sizes.

## Choose an installer

| Environment | Download |
| --- | --- |
| Windows 10 1809+ / 11, Intel or AMD x64 | `CodexQuotaStrip-windows-x64-setup.exe` for per-user install, or `CodexQuotaStrip-windows-x64.zip` for portable use. Extract all files and keep the watchdog helper beside the app. |
| Ubuntu 22.04/24.04 or Debian 12, amd64 | `CodexQuotaStrip-linux-x86_64.deb`, installed with `sudo apt install ./CodexQuotaStrip-linux-x86_64.deb`. |
| Fedora 43, x86_64 | `CodexQuotaStrip-linux-x86_64.rpm`, installed with `sudo dnf install ./CodexQuotaStrip-linux-x86_64.rpm`. |
| Other glibc Linux x86_64 / no sudo | `CodexQuotaStrip-linux-x86_64.tar.gz`; extract and run `bash install.sh`. System runtime libraries are required. |
| macOS 14+, Apple Silicon or Intel | `CodexQuotaStrip-macos-universal.dmg` for drag-and-drop into Applications, or the corresponding `.pkg` installer or `.zip` app archive. |

Quit the old app before updating. Use the same install location to preserve settings and CSV logs. If the Windows watchdog is registered, remove the old service before upgrading the component and register it again afterward. On Linux, the overlay requires X11; Wayland supports tray use. macOS preview builds are ad-hoc signed without notarization; window following requires Accessibility permission. Windows ARM64 emulation and physical macOS 14 were not tested separately.
