# 每次工作请求的用量记录

- 口径：一次 `task_started` 到 `task_complete`／`turn_aborted` 是一条请求；合计期间多次模型响应的 Token。累计计数差分，缓存输入和推理输出是子集，不再次加入总量。
- 本地事件缺少实际逐请求账单金额时显示“—”。账户额度是该请求期间观测到的账户快照变化，可能包含并发工作，不称为单请求扣费。不按 API 单价估算订阅费用。
- 来源：仅本地 rollout 的请求标识、模型、时间、状态、数字计数与额度字段；不保存提示词、回复、工具内容、账户凭据。仅记录监听启动后完成的请求；缺少开始或计数基线时标记部分记录。
- 存储：沿用已有日志启用开关及自选目录，独立 `request-usage-YYYY-MM-DD.csv`，限量读取最近 30 天／2 MiB／2000 行；不自动删除用户日志。
- Windows 复用目录通知和文件游标；Linux／macOS 使用原生文件事件；不增加账户查询、模型请求或持续轮询。
- 查看：原生列表／图表，中文／英文，列表含模型、状态、各 Token 数、额度快照变化及未知金额。图表展示各请求 Token，不将缺失值当 0。
- 验证：共享解析／存储先红后绿；真实文件通知及 UI fixture；跨平台 CI 构建、测试、打包；安装前备份并保留个人配置。
